# Controle de Gastos — versão completa

Aplicação web para registrar e acompanhar gastos pessoais, 100% no navegador. Sem servidor, sem cadastro e sem custo: os dados ficam salvos no próprio navegador (localStorage).

Projeto pessoal de estudo e portfólio, feito com HTML, CSS e JavaScript puro.

## Como rodar

Basta abrir o arquivo `index.html` no navegador — não precisa instalar nada.

## Situação

Versão completa do projeto, com o roadmap inteiro implementado (ver `docs/PLANO.md`). Instruções completas de uso e publicação serão detalhadas no README ao final.
